PAT 발급 실습
2026-10-30 사용자가 제공한 GitHub 개인 액세스 토큰(클래식) 목록 화면으로 기존 발급 사실을 확인했다.
표시된 만료일은 2026-10-11이고 사용 기록은 없으므로 해당 PAT는 현재 인증에 재사용할 수 없다.
OAuth 로그인과 PAT 발급은 별도 절차다. 이번 Git push와 SourceTree 연결은 별도로 완료한 OAuth 인증 결과다.
기존 발급 확인 대기 상태는 해소했다. 이번 작업에서 새 PAT를 발급·갱신하거나 이 PAT를 사용한 것은 아니다.
생성된 토큰 값은 기록·저장소·배포 ZIP에 포함하지 않는다.
사용자 계정 설정 화면 원본도 배포하지 않고 발급 여부와 만료 상태만 기록했다.

학교에서 받는 결과
학교용 완성 ZIP에는 cat·oct의 .git 이력, 실습 파일, 이 기록, 핵심 정리,
교재 사진 대조표, 실제 화면, 학교에서_확인.ps1을 포함한다.

그 PC의 환경 설정이며, 파일과 커밋을 처음부터 다시 만드는 과제가 아니다.

SourceTree 실행 복구
현재 정상 작동을 확인한 버전은 공식 서명된 3.4.31이다.
마법사를 실제 완료한 뒤 저장되지 않은 진행 상태를 백업 후 복구하고,
HTTPS 실습에 필요하지 않은 SSH 에이전트 자동 시작을 해제했다.
이후 Add·History·스테이징·커밋·Push의 실제 동작을 검증했다.

교수님의 별도 제출 양식은 교재 사진에 포함되어 있지 않다.
