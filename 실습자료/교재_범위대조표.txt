SourceTree 첫 실행 문제와 복구 기록
3.4.32와 3.4.31 모두 마법사의 마지막 단계 후 메인 창이 나타나지 않았다.
따라서 버전만 낮춰 문제가 해결됐다고 판단하지 않는다. .NET 4.8 요구는 충족했다.
로그에 소유 창이 없다는 알림 오류가 있었으나, 이는 원인 자체를 확정하는 예외가 아니었다.
마법사를 실제 완료한 상태에서 user.config를 먼저 백업하고 다음 일반 설정을 복구했다.
FirstLaunch=False / FirstLaunchSinceHgAdded=False / AutoStartSSHAgent=False.
앞의 두 값은 마법사 반환 후 지정되고 SSH 질문 처리 뒤 저장되는 진행 상태다.
마지막 값은 HTTPS를 사용하는 이 실습에서 선택적 SSH 에이전트 자동 시작을 끈다.
이후 메인 창과 실제 Add·History·staging·commit·push 동작을 확인했다.
라이선스·EULA·계정 인증·접근 권한 설정과 Windows 보안 설정은 변경하지 않았다.
공식 설정 파일 안내: https://support.atlassian.com/sourcetree/kb/edit-sourcetree-configurations-without-opening-the-application-windows/
범위 해석 정정
이전 정리에서 한국어 확장과 밝은 테마를 단순 취향 설정으로 남겨 둔 것은 교재의 실제
환경 설정 절차를 충분히 반영하지 못한 해석이었다. 교재는 이후 설명을 한국어 기준으로 하고
밝은 테마로 바꾸는 절차도 제시한다. 두 절차를 실제 수행·검증한 상태로 이 문서를 정정했다.
또한 GCM·브라우저 인증 또는 SourceTree OAuth의 성공을 PAT 발급 완료와 동일하게 취급하지 않는다.
PAT는 사용자 제공 화면으로 기존 발급 사실을 확인하여 확인 대기를 해소했다. 해당 PAT의 만료와 현재 OAuth 연결은 구분해 기록했다.
