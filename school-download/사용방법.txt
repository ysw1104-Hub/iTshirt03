iTshirt03 사용 방법

README.txt, feature-list.md, tshirt-list.md와 Git 이력을 담은 실습 저장소입니다.
iTshirt-cat과 iTshirt-oct는 .git을 포함한 두 실습 폴더다.

1. 압축을 전부 푼다. Git·SourceTree·VS Code가 설치되어 있어야 한다.
2. SourceTree에서 Add를 선택하고 iTshirt-cat을 등록한다. 필요하면 iTshirt-oct도 등록한다.
3. VS Code에서 같은 폴더를 열어 README.txt, feature-list.md, tshirt-list.md를 확인한다.
4. 학교 PC의 GitHub 계정 연결은 SourceTree의 Remote에서 GitHub·OAuth로 설정한다.
5. VS Code의 Microsoft 한국어 확장을 설치하고 표시 언어 ko로 재시작한 뒤 Light+ 테마를 고른다.

이력 확인: git log --oneline --decorate
작업 상태 확인: git status --short --branch
수정안은 처음 4개 실습 커밋을 그대로 유지하며 마지막 제목만 목록 문서 형식 정리로 정리했다.
교재 3개 파일 내용은 기존 실습 결과와 동일하다.
기존 화면 캡처와 자세한 수행 기록은 별도의 이전 배포본과 변경전 이력 백업에 보존한다.
